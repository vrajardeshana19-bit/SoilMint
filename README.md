# 🌱 SoilMint

> **AI-Powered Farm Intelligence & Carbon Credit Platform for Sustainable Agriculture**

SoilMint is an AI-powered Farm Intelligence platform that enables farmers to digitize their farms, assess sustainability, estimate carbon credits, and unlock new income opportunities through verified carbon markets.

By combining Artificial Intelligence, Government Land Records, Satellite Imagery, Weather Intelligence, and Soil Analytics, SoilMint simplifies sustainable farming while helping farmers improve productivity and participate in the growing carbon economy.

---

# 🚀 Vision

Our vision is to build the **Digital Operating System for Sustainable Agriculture**, empowering farmers with AI-driven insights, verified farm intelligence, and carbon market accessibility to create a more profitable and climate-resilient future.

# ⚙ Getting Started

## Clone the Repository

```bash
git clone https://github.com/vrajardeshana19-bit/SoilMint.git
```

## Navigate to the Project

```bash
cd SoilMint
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```
